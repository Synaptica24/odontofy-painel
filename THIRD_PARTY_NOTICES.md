# Avisos de terceiros

## Bencho (bencho.dev)

Os componentes abaixo foram adaptados de blocos **gratuitos** do Bencho, distribuídos sob a licença MIT, a partir da adaptação já feita no Brio (sistema da barbearia Figars). O código foi traduzido para o idioma do projeto (motion/react, tokens de cor do painel, textos em português) e ajustado ao uso no consultório.

| Componente no painel | Bloco original |
|---|---|
| `components/fx/numero-rolante.tsx` | Rolling counter |
| `components/fx/ilha-proximo.tsx` | Dynamic island |
| `components/fx/pilha-atencao.tsx` | Toast stack |
| trechos correspondentes em `styles/fx.css` | CSS dos blocos acima |

Os blocos **Pro** do Bencho não foram copiados: não há licença Pro neste projeto.
